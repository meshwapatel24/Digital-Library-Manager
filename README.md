## Project Description
Digital Library Manager is a Python-based desktop application used to manage a personal digital book collection.

## Features
- Add Book
- Update Book
- Delete Book
- Search Book
- Filter Books by Genre
- Calculate Total Books
- Calculate Average Rating
- Genre Chart
- Rating Distribution Chart

## Technologies Used
- Python
- Tkinter
- Pandas
- Matplotlib
- CSV File Handling

## Project Files
- main.py – Main Tkinter GUI
- library.py – Book management operations
- storage.py – CSV file handling
- charts.py – Data analysis and charts
- books.csv – Book data storage

## How to Run
1. Install Python.
2. Install required libraries:
   `pip install pandas matplotlib`
3. Open the project folder in VS Code.
4. Run `main.py`.

## Output
The application provides a graphical interface for managing books, searching and filtering records, displaying collection summaries, and generating charts.
